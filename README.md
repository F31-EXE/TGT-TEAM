# TGT Team — приложение страйкбольной команды

Мобильное веб-приложение (PWA) для учёта командных финансов и жизни команды.
Устанавливается на телефон как обычное приложение, работает без интернета.

## Возможности

- **💰 Взносы** — ежемесячный список участников: кто внёс, кто нет, кто частично.
  Итог «собрано / ожидается / не хватает», прогресс-бар, переключение месяцев.
  Отметка оплаты одним тапом, частичная оплата, погашение долга за прошлые месяцы.
- **📣 Отчёт в чат** — готовый текст для Telegram/WhatsApp: кто внёс, кто нет, баланс казны.
- **⏰ Напоминание должникам** — список долгов по месяцам (с @никами из Telegram).
- **👥 Состав** — позывной, имя, роль, контакт, дата вступления, освобождение от взносов,
  уход из команды (история взносов сохраняется).
- **🧾 Казна** — баланс, расходы и прочие поступления по категориям
  (полигон, пиротехника, снаряжение…).
- **🎯 Игры** — календарь игр и тренировок, сбор «кто едет» (✅ / ❓ / ❌), отправка состава в чат.
- **🎒 Имущество** — командное снаряжение и у кого оно на руках.
- **Резервная копия** — экспорт/импорт данных в JSON-файл.

## Установка на телефон

1. Опубликуйте репозиторий через GitHub Pages:
   *Settings → Pages → Source: Deploy from a branch → ветка, папка `/ (root)`*.
2. Откройте полученную ссылку на телефоне:
   - **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
   - **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».

## Где хранятся данные

Данные хранятся локально на телефоне (localStorage). Удобнее всего, чтобы учёт вёл
казначей, а остальные получали отчёты в чат. Регулярно делайте экспорт
(вкладка «Ещё» → «Экспорт») — файл можно передать новому казначею.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

После изменения файлов увеличьте версию `CACHE` в `sw.js`, чтобы телефоны получили обновление.

# TGT Team — приложение страйкбольной команды

Мобильное веб-приложение (PWA) для команды: взносы, казна, состав, игры, посещаемость, дни рождения.
Ставится на телефон как обычное приложение, работает и без интернета.

## Возможности

- **💰 Взносы.** Ежемесячный список: кто внёс, кто нет, кто частично. Итоги «собрано / ожидается / не хватает».
  Переплата не теряется: сначала гасит старый долг, остаток идёт **авансом** на следующие месяцы
  («внёс 900 — три месяца не спрашивать»). Напоминание о взносах с реквизитами — в дни, указанные в настройках (по умолчанию 1-е и 22-е).
- **Статусы.** *Активен*, *Пауза* (взносы не начисляются), *Покинул*. *Рекрут* не платит взносы. Кнопкой «⭐ В бойцы» его переводят в *бойцы*, и взнос начисляется
  с месяца принятия. Можно также освободить от взносов и отметить уход из команды (история сохраняется).
- **Роли.** *Админ* ведёт учёт. *Участник* видит взносы, свой долг, казну, игры и отмечается на играх («еду / думаю / не еду»).
  Вход по логину и личному PIN, которые выдаёт админ.
- **Общая база (Firebase).** Все видят одни и те же данные в реальном времени.
- **ВКонтакте.** Профили бойцов. Отчёты, напоминания должникам и состав на игру с @упоминаниями —
  готовый текст для беседы ВК.
- **★ Звания и баллы по Положению о балльной системе.**
  - Каждые 50 баллов — новое звание (таблица званий редактируется в настройках).
  - Игры: простая 2, платная 3, суточная 10 — начисляются автоматически по отметке «еду» на прошедших играх.
  - Остальное админ начисляет из готового списка пунктов Положения: подвоз, работы на полигоне, медиа,
    девайсы и ПО, такмед, наставничество, судейство, рекрутинг; штрафы за дисциплину и ТБ.
  - Норма 18 баллов за квартал. «Старичок» за невыполнение получает штраф −50 баллов за квартал,
    остальные попадают в список кандидатов на исключение. Проверка нормы ведётся с квартала, указанного в настройках.
  - Академический отпуск: 1 месяц, не более 2 в календарном году; в месяц отпуска в норму засчитывается 18 баллов.
  - Номер бойца (TGT-xx), группа и командир группы.
- **Заявки на баллы.** Боец сам подаёт заявку по пункту Положения (ссылка, фото); админ принимает или отклоняет с причиной.
- **«Я перевёл».** Боец отмечает оплату взноса или сбора и прикладывает скрин чека; после проверки админом сумма
  попадает в учёт. Фото сжимаются в телефоне (~100 КБ) и хранятся в базе — платный Firebase Storage не нужен.
- **Факт присутствия.** После игры админ отмечает, кто реально приехал; баллы и посещаемость считаются по факту.
- **Подвоз.** Водитель указывает свободные места, бойцы записываются; водителю +1 балл за каждого пассажира.
- **Целевые сборы** (суточная игра, палатка) отдельно от взносов: цель, сумма с человека, кто сдал, напоминание в ВК.
- **Хрон-журнал.** Привод, скорость, масса шара, энергия в джоулях.
- **Чек-лист перед игрой** (список настраивается) и сводка, кто собрался полностью.
- **Положение о балльной системе** внутри приложения; админ может редактировать текст.
- **Атмосфера Pip-Boy:** загрузочный экран терминала (один раз за сессию, касание — пропустить), звук щелчков (выключается в «Ещё»).
- **📊 Посещаемость.** Рейтинг бойцов по прошедшим играм и статистика в карточке каждого.
- **🎂 Дни рождения.** Баннер за 2 недели, кнопка «Поздравить». Экспорт всех ДР в календарь телефона (.ics)
  с напоминанием за день.
- **Excel.** Выгрузка всего в .xlsx (состав, взносы по месяцам, казна, игры, посещаемость, имущество) и
  загрузка ваших таблиц (см. ниже).
- **🧾 Казна** с категориями расходов, **🎒 имущество** команды, резервная копия JSON.

## Общая база: настройка (один раз, ~15 минут, бесплатно)

Пока `firebase-config.js` не заполнен, приложение работает в **локальном режиме**: данные хранятся только на одном телефоне, а ролей нет.

1. Зайдите на <https://console.firebase.google.com> под Google-аккаунтом и нажмите **«Создать проект»**.
   Google Analytics можно отключить.
2. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable**.
   Почты не нужны: приложение само создаёт технические учётки для логинов и PIN.
3. **Build → Firestore Database → Create database**: режим *production*, регион `eur3 (europe-west)`.
4. **Firestore → вкладка Rules**: замените текст на содержимое файла [`firestore.rules`](firestore.rules) и нажмите **Publish**.
5. **⚙️ Project settings → General → Your apps → значок `</>` (Web)**: зарегистрируйте приложение.
   Скопируйте значения из блока `firebaseConfig` в [`firebase-config.js`](firebase-config.js) и закоммитьте файл.
   Эти ключи не секретные — доступ защищают правила из шага 4.
6. **Authentication → Settings → Authorized domains**: добавьте домен, на котором открывается приложение
   (например `ваш-ник.github.io`).
7. Откройте приложение и нажмите **«Первый запуск: создать команду»**. Вы станете первым админом.
   Сделать это можно только один раз: после создания команды повторно её не создать.
8. Добавьте бойцов (или загрузите из Excel). В карточке бойца нажмите **«Изменить» → «🔑 Выдать логин и PIN»**
   и отправьте ему текст в личные сообщения ВК.

**Перенос данных из локального режима:** на старом телефоне откройте «Ещё» → «⬇️ Копия», затем в общей базе под админом нажмите «⬆️ Загрузить».

Админ может сменить бойцу PIN, назначить или снять права админа и закрыть доступ. Закрытие доступа срабатывает сразу.

## Импорт из Excel

«Ещё» → «⬆️ Загрузить из Excel» (.xlsx, .xls, .ods, .csv). Перед загрузкой приложение показывает, что именно распознало.
Существующие данные не удаляются.

Распознаются листы такого вида (порядок столбцов и названия листов неважны):

| Что | Пример заголовков |
|---|---|
| Взносы «боец × месяцы» | `ФИО` / `Позывной`, `Январь`, `Февраль`… или `01.2026`, `янв 26`, даты |
| Взносы списком | `Позывной`, `Месяц` (или `Дата`), `Сумма` |
| Состав | `Позывной`, `ФИО`, `ВК`, `Дата рождения`, `Статус` (рекрут/боец), `Дата вступления` |
| Казна | `Дата`, `Описание`/`Статья`, `Сумма` (или отдельные `Приход` и `Расход`) |
| Строки под таблицей взносов | `С прошлого периода` (остаток), `Проценты от вклада`, `Доп. приход` — уходят в казну |
| Балльная система (.csv/.xlsx) | `Позывной` вида `Молчун (TGT-08) (Группа управления)`, `Игры`, `Походы`, `Вклад`, `Штраф…`, `Кол-во баллов…`, таблица `Кол-во баллов → Звание` |

В ячейках взносов понимаются суммы (`300`, `1 000 ₽`), отметки `+`, `да`, `✓` (= полный взнос) и `-` (закрыто авансом).
Размер взноса определяется по самой частой сумме. Статусы из листа состава: Активен / Пауза / Покинул / Рекрут.
Бойцы сопоставляются по позывному; если в базе бойца нет, он будет создан. Повторная загрузка того же файла не задваивает данные.

## Установка на телефон

Опубликуйте репозиторий через GitHub Pages: *Settings → Pages → Deploy from a branch*, корневая папка.
Откройте ссылку на телефоне:
- **Android (Chrome):** меню ⋮ → «Установить приложение»;
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

## Разработка

```bash
python3 -m http.server 8000            # http://localhost:8000
# Проверка с эмуляторами Firebase (нужна Java):
npx firebase-tools emulators:start --project demo-tgt
# и открыть http://localhost:8000/?emu=1 (при заполненном firebase-config.js)
```

Сборка не нужна. Firebase SDK и SheetJS лежат в `vendor/`, внешние CDN не используются.
После изменения файлов увеличьте версию `CACHE` в `sw.js`, чтобы телефоны получили обновление.
